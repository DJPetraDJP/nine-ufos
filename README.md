# NINE UFOS

3D Nine Men's Morris in the browser. Gold UFOs versus a pink computer fleet.

## Play

Open this file in a current browser:

- [index.html](index.html)

Or enable **GitHub Pages** on this repository (Settings → Pages → Deploy from branch `main` / root). The public address will then be:

https://djpetradjp.github.io/nine-ufos/

Requires an internet connection on first load (Three.js from unpkg).

## Controls

- Drag to orbit the board
- Scroll to zoom
- Click a beacon to place or move
- **Preview & Play** starts a new game

## Rules

Nine craft each. Place all pieces, then slide along the rings. Three allied UFOs in a line form a mill and capture one enemy (not from a mill, unless every enemy piece is in a mill). With three ships left, a side may jump to any empty beacon. Win by reducing the opponent below three pieces or leaving no legal move.
